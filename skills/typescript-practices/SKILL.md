# Loopfive's TypeScript practices

The practices are in `README.md` at the root of this plugin, two folders up from this file (`../../README.md`). Read it in full: each rule has a bad example, a good example and the reason.

Check the code you wrote, changed or are reviewing against every rule:

1. List the rules the code touches.
2. For each one, compare the code with the rule's good example.
3. Fix what breaks a rule, in the same change. In a review, report it with the rule's title.

Where another guide disagrees (pstack's `typescript-best-practices`, Ponytail, a framework's docs), these practices win. A project's own conventions (its `CLAUDE.md`, linters) still apply on top.
